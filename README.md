# Ponos Stream

Мини-прототип для совместного просмотра видео и аудио в полный экран через десктопное приложение.

## Быстрый старт

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите десктопное приложение:
   ```bash
   npm start
   ```
3. Приложение откроется отдельным окном. На двух устройствах введите одинаковую комнату.
4. Один участник выбирает роль отправителя, другой — получателя.

## Примечания

- Приложение использует Electron, внутри запускается локальный сервер сигналинга.
- Поток идёт по WebRTC, сигналинг — через WebSocket.
- Работает с локальными видео/аудио файлами отправителя.
