# Ponos Stream

Мини-прототип для совместного просмотра видео и аудио в полный экран через браузер.

## Быстрый старт

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите сервер:
   ```bash
   npm start
   ```
3. Откройте `http://localhost:3000` на двух устройствах, выберите одинаковую комнату.
4. Один участник выбирает роль отправителя, другой — получателя.

## Примечания

- Поток идёт по WebRTC, сигналинг — через WebSocket.
- Работает с локальными видео/аудио файлами отправителя.
